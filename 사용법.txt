다챱고 브라우저 (Dachapgo Browser) — 사용법
=============================================

1. 설치
   - zip 을 원하는 폴더(예: C:\Dachapgo)에 통째로 풉니다. 한글·공백 없는 경로를 권합니다.
   - Dachapgo.exe 를 실행합니다. 처음 한 번은 Windows 가 "알 수 없는 게시자" 경고를 띄울 수 있습니다
     → [추가 정보] → [실행].
   - 바탕화면 바로가기가 필요하면 명령 창에서: Dachapgo.exe --create-shortcuts

2. 라이선스 받기
   - 앱이 열리면 [🔑 라이선스 인증 · 발급 관리] 탭에 이 PC 의 HWID(DCG-XXXX-XXXX-XXXX)가 보입니다.
   - 라이선스는 다챱고 대표가 직접 발급합니다. 받은 키(DACHAPGO1.로 시작)를 같은 탭의 '라이선스 키 등록 / 변경' 칸에
     붙여 넣고 [🔑 라이선스 키 인증 및 적용]을 누릅니다.
   - 키 하나로 쓸 수 있는 PC 대수는 발급한 쪽이 정합니다. 인터넷에 하루 한 번 확인하며,
     인터넷이 끊겨도 마지막 확인 뒤 7일까지는 그대로 쓸 수 있습니다.

3. 쓰기
   - 대시보드: http://127.0.0.1:50330/dachapgo
   - AdsPower 호환 Local API: http://127.0.0.1:50330/api/v1/...  (연결 방법은 [📘 API 연결 문서 & 연동 가이드] 탭)
   - Local API 키: 처음 켤 때 data\API_KEY.txt 에 만들어집니다(Authorization: Bearer <키> 또는 X-API-Key: <키>).
   - 프로필·쿠키·설정은 모두 이 폴더의 data\ 에 저장됩니다.

4. 새 판으로 올리기
   - https://github.com/ptliv/dachapgo-browser/releases/latest 에서 새 zip 을 받아
     앱을 끈 뒤 같은 폴더에 덮어 풉니다. data\ 폴더(프로필·라이선스)는 그대로 남습니다.

5. 끄기
   - 작업 관리자에서 Dachapgo.exe 를 끄거나 PC 를 다시 켜면 서버도 꺼집니다.
